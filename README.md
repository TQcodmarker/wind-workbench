# 📊 地方债工作台

**地方债数据查询 · 样本汇总 · 历史追踪 · 数据溯源**

本机运行的地方债数据工作台，支持 AKShare 与 Wind 双数据源。

`⚛ React` · `TypeScript` · `Vite` · `🐍 FastAPI` · `SQLite`

## ✨ 核心功能

| 功能 | 说明 |
| :--- | :--- |
| 🔌 **双数据源** | 切换 AKShare / Wind，自动保存选择，数据与任务按来源隔离 |
| 📈 **估值工作台** | 按地区、发行日期组、期限和债券类型查看数据，支持筛选、个券详情与 CSV 导出 |
| 🔄 **全量同步** | 获取公开地方债目录与静态资料，支持进度查看、暂停和断点继续 |
| 🗂️ **历史追踪** | 保存历史结果与更新记录，支持失败重试，保留已有成功快照 |
| 🔍 **数据溯源** | 核对原始请求、响应和逐字段来源，导出完整证据 |
| 💬 **规则助手** | 查询数据、比较历史与生成模板摘要，结果绑定日期和快照版本 |

## 🚀 快速启动

**环境要求：** Windows / PowerShell、Node.js 20.19+（或 22.12+）、Python 3.11+。

在项目根目录运行：

```powershell
.\start.ps1
```

脚本会检查并安装所需依赖、构建前端并启动服务。启动后访问 **[地方债工作台](http://127.0.0.1:8765)**，按 `Ctrl+C` 停止网页服务。

1. 在「数据源」页选择 **AKShare**（默认）或 **Wind**；使用 Wind 时先配置 Key。
2. 选择目标日期，手动创建更新任务；切换数据源或刷新页面不会触发采集。
3. 查看个券与汇总结果，按需筛选、查看来源或导出 CSV。

需要补齐地方债目录与静态资料时，在 AKShare 页面点击 **「全量同步地方债」**。任务可暂停并继续；运行期间需保持电脑开机、联网及后台进程运行。

<details>
<summary>🎮 使用合成数据体验演示模式</summary>

在启动前设置：

```powershell
$env:WIND_DATA_MODE = 'demo'
.\start.ps1
```

演示模式使用独立数据库，行情为合成数据。恢复真实模式时，将 `WIND_DATA_MODE` 设为 `wind` 后重新启动。

</details>

## 🧭 数据说明

| 数据源 | 主要口径 |
| :--- | :--- |
| **AKShare** | 公开目录、静态资料与个券成交到期收益率；符合条件的同日样本按发行规模加权，并按自行估算的修正久期分组 |
| **Wind** | 新任务采用收盘价到期收益率；已有快照保留原口径与规则版本 |

- **覆盖范围：** 目录和静态资料完整不代表每日个券行情完整；部分样本不会发布为全国完整估值结果。
- **缺失数据：** 缺失字段保持为空，不用最新行情回填历史；公开成交收益率与估算久期不等同于中债逐券估值。
- **助手能力：** 当前使用规则解析与模板摘要；大模型配置页支持连接测试，尚未接入行情解读。
- **更新方式：** 由用户手动发起，尚未启用每日定时更新。

数据保存在本机 `runtime/` 目录。默认 `WIND_DATA_MODE=wind` 表示**真实模式**，不强制选择 Wind 数据源；真实库与演示库分别使用 `wind-wind.sqlite3` 和 `wind-demo.sqlite3`。

## 🛠️ 开发指南

完成首次启动后，保持后端运行，另开终端启动前端开发服务：

```powershell
npm.cmd run dev
```

访问 [前端开发服务](http://127.0.0.1:5173)，`/api` 请求会代理到本机后端。接口说明见 [API 文档](http://127.0.0.1:8765/docs)。

### 项目结构

```text
src/          React 页面与交互组件
backend/      FastAPI 服务、数据采集、计算与存储
scripts/      数据核验与辅助脚本
tests/        后端测试与浏览器验证
docs/         需求、设计与使用说明
research/     数据核验与性能验证记录
runtime/      本机运行数据，不纳入版本控制
```

### 构建与验证

```powershell
npm.cmd run build
.venv\Scripts\python.exe -m unittest discover -s tests -v
npm.cmd run test:e2e
```

浏览器测试需要本机 Chrome，使用 `8766` 端口的独立服务和测试数据库。报告与截图保存在 `test-results/`。

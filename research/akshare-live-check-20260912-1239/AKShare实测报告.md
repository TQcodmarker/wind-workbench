## 原表字段可替代程度

| 字段 | 实测结论 |
|---|---|
| A/C证券代码、简称，G票息，S发行日 | 4只样本已验证；代码需保留市场映射 |
| B地区、F一般/专项 | 可由发行人、债券全称整理；四只样本成立 |
| D剩余期限，N期限分组，T日期标志 | 有日期输入后可计算；D需匹配Wind计年口径，不能直接声称精确一致 |
| E未偿余额 | 本次未取得等价字段；发行量不可替代 |
| H中债修正久期、J中债估值收益率 | 本次所测接口未取得对应逐券字段；成交收益率不可填作中债估值 |
| I地方债曲线 | 可取得中国货币网AAA/AAA-曲线；尚不能等价替代原表指定曲线 |
| O/R提前偿还或赎回 | 出现不一致反例，不能用exerciseInfoFlag直接替代，仍需偿还安排 |
| K/P调整收益，L/M利差，Q久期×余额 | 公式可复写，但缺少估值、余额或久期时无法完整计算 |

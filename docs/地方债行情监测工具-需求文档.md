# 地方债行情监测工具需求文档

## 1. 建设目标

借助AI实现一个地方债行情监测工具，自动连接Wind获取数据，按照约定的分组和计算规则生成汇总结果，每天自动更新，并保留历史结果，支持按日期查看。

在已保存的汇总数据基础上，增加三个AI功能：自然语言查询、历史对比与解读、每日行情摘要。具体要求见第9节。取数、筛选、期限归类和加权计算继续由固定程序执行，AI负责理解查询意图和组织有数据依据的说明。

本文依据用户最新确认的口径编写，并结合《地方债二级盯盘.xlsx》的数据结构和展示形式。与参考表或早期描述不一致的地方，以用户最新确认的口径为准。用户已授权系统架构师和数据工程师决定剩余细节，相关决策及理由列在第8节。

## 2. 数据来源与基础数据

数据来源为Wind。获取地方政府债的全量基础信息和评估日数据，以单只债券为处理单位。

| 数据项 | 已明确的含义或用途 |
|---|---|
| 证券代码 | 识别单只债券，并与Wind取数结果对应 |
| 债券类型 | 区分一般债、专项债 |
| 发行地区 | 用于逐地区统计和展示 |
| 中债估值 | 使用参考表中的中债估值收益率字段，作为加权平均的计算对象 |
| 发行日期 | 用于2025年8月8日前后的分组 |
| 剩余期限（年） | 用于四舍五入取整及期限分类 |
| 久期 | 用户此前提出的基础字段，保留原始含义；期限分类使用剩余期限 |
| 发行规模 | 作为中债估值加权平均的权重 |
| 提前偿还、赎回条款信息 | 用于排除存在相应条款的债券 |
| 评估日期 | 标识本次取数和汇总结果所属的日期 |

参考表使用的“评估日存量余额”与本需求的“发行规模”是不同字段。取数时应获取实际发行规模，保持字段含义准确。

每天处理运行日期前一个自然日的数据。与评估日期有关的估值、剩余期限等字段，应按该数据日期获取。运行日期与实际估值日期分别记录，具体无数据和取数失败处理见第5节。

## 3. 数据处理流程

处理顺序为：获取全量债券基础信息和评估日数据，剔除缺失记录及提前偿还、赎回条款债，按剩余期限取整并筛选目标年份，再按发行日期组、地区、期限类别和债券类型计算发行规模加权平均值，形成并保存该评估日的结果。

### 3.1 统计前的数据筛选

- 从统计输入中剔除计算所需字段缺失的记录。计算所需信息包括证券代码、发行地区、债券类型、发行日期、中债估值、剩余期限、发行规模及用于判断提前偿还、赎回的信息。
- 空值、空字符串、非数值标记以及接口返回的错误值，均不得转换为数值0后参与计算。
- 发行规模必须是有效数值且大于0，否则剔除。
- 中债估值收益率必须是数据源正常返回、对应目标估值日期的有效数值。有效的数值0保留；接口错误、缺失占位或日期不匹配的值剔除。
- 排除存在提前偿还或赎回条款的债券。
- 按第3.4节的期限规则筛选，仅保留符合目标年份的债券。

可以保留获取到的全量原始数据，在计算时执行上述筛选。每只债券在同一估值日、同一统计组内只计入一次。缺失值和真实数值0分别识别。

### 3.2 按发行日期分组

以2025年8月8日为分界，将债券划分为两组，分别计算和展示。

| 分组 | 发行日期条件 | 参考表名称 |
|---|---|---|
| 分界日前发行 | 发行日期 < 2025年8月8日 | 免税 |
| 分界日当天及以后发行 | 发行日期 ≥ 2025年8月8日 | 非免税 |

2025年8月8日当天发行的债券归入第二组。参考表中的“免税”“非免税”作为上述日期组的对应名称。

### 3.3 按地区分类

以每个发行地区为单位分别统计。地区按参考表分为一档、二档、三档，并保留以下顺序。

| 档位 | 地区顺序 |
|---|---|
| 一档 | 上海市、北京市、广东省、深圳市、浙江省、江苏省 |
| 二档 | 福建省、厦门市、宁波市、河北省、山东省、安徽省、山西省、河南省、湖北省、四川省、湖南省、江西省、重庆市 |
| 三档 | 内蒙古自治区、海南省、辽宁省、陕西省、西藏自治区、大连市、天津市、新疆维吾尔自治区、新疆生产建设兵团、宁夏回族自治区、青岛市、广西壮族自治区、甘肃省、吉林省、贵州省、云南省、黑龙江省、青海省 |

在参考表原有36个地区基础上，新增“新疆生产建设兵团”，单列在第三档，排在新疆维吾尔自治区之后，共37个地区。兵团债独立归属和统计，每只债券仅对应一个地区。

地区归属使用发行主体与地区的明确对应关系。旧表截取字符串得到的“新疆生产”等名称，仅在确认其债券身份属于兵团后映射为“新疆生产建设兵团”，避免与新疆维吾尔自治区重复计入。

当前结果及历史结果均以单个地区分别统计，按一、二、三档排列。

### 3.4 按期限类别归档

汇总表使用以下七个类别：

**3Y、5Y、7Y、10Y、15Y、20Y、30Y。**

对单只债券的剩余期限按通常四舍五入规则取整数，小数部分达到0.5时进一，否则舍去。仅当所得整数属于上述七个年份时，债券才参与统计。其他年份的债券排除。

```text
期限类别 = ROUND(剩余期限, 0)
保留条件：期限类别属于 {3, 5, 7, 10, 15, 20, 30}
```

| 类别 | 剩余期限范围 |
|---|---|
| 3Y | 2.5年 ≤ 剩余期限 < 3.5年 |
| 5Y | 4.5年 ≤ 剩余期限 < 5.5年 |
| 7Y | 6.5年 ≤ 剩余期限 < 7.5年 |
| 10Y | 9.5年 ≤ 剩余期限 < 10.5年 |
| 15Y | 14.5年 ≤ 剩余期限 < 15.5年 |
| 20Y | 19.5年 ≤ 剩余期限 < 20.5年 |
| 30Y | 29.5年 ≤ 剩余期限 < 30.5年 |

例如，10.4年取整为10，纳入10Y；10.5年和11年取整为11，排除；24.9年取整为25，排除；29.5年取整为30，纳入30Y。

此前的“11年归10Y”示例和参考表“达到25年统一归30Y”的规则，均由本节最新规则替代。

### 3.5 按债券类型统计

对每个发行日期组、每个地区、每个期限类别，分别形成以下三个统计结果：

| 统计口径 | 纳入范围 |
|---|---|
| 整体 | 符合当前分组条件的全部债券 |
| 一般债 | 符合当前分组条件的一般债 |
| 专项债 | 符合当前分组条件的专项债 |

“整体”应直接基于该组内符合条件的单只债券计算。

### 3.6 计算中债估值的加权平均值

本次需求明确采用发行规模加权平均。

设同一组内第i只债券的中债估值收益率为yᵢ，发行规模为aᵢ，则：

```text
组内中债估值加权平均值 = Σ(yᵢ × aᵢ) ÷ Σ(aᵢ)
```

分子、分母使用同一组符合条件的债券。每组同时对应发行日期分组、地区、期限类别和债券类型口径。

各券发行规模使用一致单位。参考Excel中的算术平均公式由上述发行规模加权公式替代。

没有合格债券，或有效发行规模合计不大于0时，汇总值保存为空值，页面显示“—”。不以收益率0代表没有样本。

每组同时保存合格样本数量及参与计算的发行规模合计，供汇总说明和历史对比使用。这两项统计与收益率使用同一组符合条件的债券；空组样本数量和规模合计为0，收益率仍为空值。

## 4. 汇总结果展示

参考《地方政府债估值及利差汇总》的地区和期限排列结构，展示中债估值的加权平均结果。

- 显示结果所属的评估日期。
- 默认展示最近一个已保存的有效估值日，并明确显示实际日期；支持选择日期查看历史。
- 分别展示分界日前、分界日当天及以后发行债券的结果。
- 行按地区排列，并显示一档、二档、三档分组。
- 列分为“整体”“一般债”“专项债”三组。
- 每组均包含3Y、5Y、7Y、10Y、15Y、20Y、30Y七个期限类别。
- 每个结果对应明确的日期分组、地区、期限类别和债券类型口径。
- 某组没有合格样本时显示“—”；目标日期未发布独立估值数据时显示“当日无估值数据”。

最终结果的计算对象为中债估值收益率。参考表中“平均免税收益”等旧表头，应与本次实际展示指标保持一致。

## 5. 每日更新与历史查询

历史数据起点确定为**2026年9月1日**。系统实际部署后，每天**北京时间上午9:00（Asia/Shanghai）**启动，处理前一个自然日的数据，完成以下流程：

1. 将运行日期的前一天确定为本次数据日期。
2. 检查目标日期是否存在独立估值数据，从Wind获取该日期所需数据。
3. 执行缺失记录、条款和期限筛选，进行分类及发行规模加权计算。
4. 更新对应评估日期的汇总结果。
5. 保留以前日期的结果。
6. 当日汇总完整保存成功后，生成该评估日的AI行情摘要。AI生成失败不影响已保存的行情结果，具体见第9.4节。

用户可以选择评估日期，查看对应日期的汇总结果。不同日期的结果应能够分别查询，后续更新不能覆盖其他日期已保存的历史结果。

### 5.1 非交易日、无数据与取数失败

- 是否存在当日估值，以数据源返回的估值所属日期和数据状态为准，不仅凭星期几判断。
- 如果前一天没有独立估值数据，该日不写入新的估值数值。查询该日时显示“当日无估值数据”，已有历史保持不变。
- 不将上一交易日的估值改标为前一天的估值，不把Wind自动向前填充的数值认作新的当日估值。
- Wind连接或接口错误导致未取到数据时，将本次运行记为取数失败，保留该日期已有的成功结果；不将接口故障记成“市场当日无估值数据”。
- 后续日常运行补取此前因失败或延迟未保存、且数据源实际已发布估值的日期。

### 5.2 历史起点与初始回补

历史留存按数据日期划分，保留**2026年9月1日当天及之后**的数据，不要求2026年9月1日之前的历史。

如果实际部署晚于2026年9月1日，首次运行补取2026年9月1日至运行前一天的可用历史数据。回补使用对应评估日期的债券范围、估值和剩余期限，不使用当前估值代替历史值，也不能只用当前仍存续的债券清单替代历史债券范围。

同一日期、同一统计组只保存一份当前有效结果。重新计算该日期成功后更新对应结果，避免重复记录；其他日期不受影响。

### 5.3 历史保存粒度

长期保留以下粒度的汇总结果：

```text
评估日期 × 发行日期分组 × 单个地区 × 期限类别 × 整体/一般债/专项债
```

一、二、三档作为地区分组属性保留，历史查询仍能看到每个省、市和兵团的结果，不仅保存三档合计。

默认长期保存汇总历史。全量个券数据用于当次筛选和统计，可以缓存或保留，但不要求长期保留每日个券明细；文件较大时可省略个券历史，同时完整保留逐地区汇总。

长期汇总除加权收益率外，还保留每组的合格样本数量、发行规模合计，以及结果生成时间和可识别本次结果版本的标识。AI查询、对比和摘要应绑定所依据的结果版本，保证数值、样本数量和规模合计来自同一份有效结果。不能用当前个券数据补造历史样本数量或规模合计。

按37个地区、2个发行日期组、7个期限类别、3个债券类型口径计算，每个数据日最多1,554个汇总位置，能够在省略个券历史的同时保留原有逐地区查询能力。

## 6. 参考文件中已发现的实现缺失

以下内容是参考文件现状，后续实现需要按本需求中的完整计算流程和展示结构处理：

- 期限分类列存在部分公式缺失，现有空白与提前偿还、赎回记录的对应关系不一致。
- “分区域－免税”的结果区尚未连接上游计算结果。
- “分区域－非免税”的15Y、20Y展示结果公式缺失。
- 部分地区查询引用失效。
- 原表已有证券代码清单，但未给出自动更新全量债券清单的流程。

这些缺失不构成新的业务筛选规则。重新获取全量数据后，按本文明确的缺失剔除、条款排除、剩余期限取整筛选和发行规模加权规则计算。

## 7. 验收内容

按以下内容验收：

- 能从Wind获取所需基础信息和评估日数据。
- 能剔除必需字段缺失、提前偿还和赎回条款债券。
- 发行规模不大于0的记录剔除；有效的零收益率与缺失值分别处理；没有合格样本的组保存为空值并显示“—”。
- 剩余期限按四舍五入取整，仅保留3、5、7、10、15、20、30这七个整数类别；取整为11、25等其他年份的债券排除。
- 能按发行日期、地区、期限类别和债券类型正确分组。
- 2025年8月8日当天发行的债券归入“当天及以后”组。
- 抽取代表性分组，用组内单券的发行规模独立计算加权平均，结果与系统一致。
- 展示表覆盖已确认的地区、三个债券类型口径和七个期限类别。
- 新疆生产建设兵团单列第三档，与新疆维吾尔自治区分别统计，无重复计入。
- 能每天北京时间上午9:00处理前一个自然日的数据。
- 前一天未发布独立估值时，不把旧估值改标为该日新值；接口失败不会覆盖已有成功结果。
- 能回补、保留并按日期查询2026年9月1日及之后的汇总结果，历史范围按实际估值日期识别。
- 在省略个券历史明细的情况下，仍能查询所保留的地区层面汇总历史。
- 能通过自然语言按日期、发行日期组、地区或档位、期限及债券口径查询已保存结果，并显示实际分析范围和对应表格入口。
- 查询条件不明确时，能说明继承的当前页面条件或向用户澄清；指定日期缺少结果时，不静默替换为其他日期。
- 能在相同分组口径下比较两个评估日，展示收益率、合格样本数量及发行规模合计的变化。合成样例中，基准日收益率1.75%、目标日1.82%时，变化应为+7BP。
- 对比任一侧收益率为空时，收益率变化为空并说明原因；有效零收益率正常参与比较。缺少历史样本数量或规模合计时，对应项标为不可用。
- 当日汇总成功保存后，能够生成带日期、分析范围、比较基准和数据入口的AI摘要；没有可用比较基准时，明确说明。
- AI生成失败不会回滚汇总结果或把行情更新标记为取数失败；同日重算成功后，AI当前查询和新摘要引用新的有效结果。
- AI回答中的数值、差值和排序与固定程序返回的结果一致；在没有个券历史或额外来源证据时，不声称完成逐券归因或确认市场变化原因。

## 8. 已补齐的设计决策

以下为用户授权后采用的系统设计选择，不表述为用户此前已经逐项指定的口径。

| 原待定事项 | 采用的决策 | 理由 |
|---|---|---|
| 零值和空组 | 无效或不大于0的发行规模剔除；数据源有效的零收益率保留；空组保存为空值、显示“—” | 收益率0和缺失是不同状态；只有正的有效发行规模参与加权 |
| 兵团归属 | 新疆生产建设兵团单列第三档 | 保留其独立统计身份，避免混入新疆维吾尔自治区结果 |
| 非交易日 | 保持“前一自然日”目标，只存该日真实发布的估值；无独立估值时保留空缺 | 使历史日期与估值实际所属日期一致 |
| 历史粒度 | 逐地区保存汇总，个券历史非必需 | 满足原有逐地区查询要求，汇总规模也较小 |
| 9月1日年份 | 采用2026年9月1日，首次运行回补至前一天 | 按本次需求讨论所在年份确定，保持约定历史范围完整 |

兵团独立展示的参考背景是财政部地方债市场报告将新疆生产建设兵团纳入发行地区统计；单列第三档是本工具的展示决策。[财政部《地方政府债券市场报告（2025年12月）》](https://kjhx.mof.gov.cn/yjbg/202602/t20260213_3983810.htm)

中债公开查询将估值日期、估价收益率、待偿期和修正久期分别列示。本工具据此保持日期和字段含义独立；非交易日不改标旧值是本工具的数据保存决策。[中国债券信息网·中债估值](https://valuation.chinabond.com.cn/cbweb-mn/val/val_query_list?locale=zh_CN)

## 9. AI功能需求

### 9.1 功能范围与职责

本期新增以下三个AI功能，围绕工作台已有的地区汇总和历史结果提供查询与解读：

| 功能 | 用户要完成的工作 | 数据依据 |
|---|---|---|
| 自然语言查询（问数据） | 用一句话找到指定日期和分组的数据 | 已保存的有效汇总结果 |
| 历史对比与解读（看变化） | 比较两个日期，了解各组收益率及样本情况的变化 | 两个日期的有效汇总、样本数量和发行规模合计 |
| 每日行情摘要（写摘要） | 减少每天手工整理行情说明的工作 | 当日及可用历史汇总、对应更新状态 |

AI解析用户意图并组织文字说明；实际查询、差值计算和排序由固定程序完成。第3节的数据筛选、发行日期分组、地区归属、期限分类及发行规模加权规则保持不变。AI操作不直接修改计算口径、删除数据或覆盖历史结果。

### 9.2 自然语言查询

支持以自然语言指定评估日期、发行日期组、单个或多个地区／地区档位、期限类别及整体／一般债／专项债口径。

示例：“查看2026年9月10日、2025年8月8日前发行、第三档地区专项债的10年估值。”系统应返回该日期、该发行组下第三档各地区对应的10Y专项债汇总，保留原有地区顺序。第三档表示地区筛选条件，不新增第三档整体加权值。

查询要求：

- 优先读取已保存的汇总结果；自然语言查询本身不启动Wind补取任务。
- 可以继承页面当前明确显示的日期、发行日期组、地区范围和债券口径。回答中列出实际使用的条件，让用户知道本次查询范围。
- 当前上下文仍不足以唯一确定查询含义时，先澄清相关条件，不擅自选择日期、期限或发行日期组。
- 指定日期无独立估值、尚未处理或获取失败时，分别说明对应状态，不用其他日期的数据代替。已有成功快照但最近重试失败时，可引用保留的成功结果，并说明其生成时间和最近更新状态。
- 某组无合格样本时说明为空组；有效收益率0正常返回。
- 回答可以使用表格与简短说明，并提供对应评估日、分组和表格位置的查询入口。

### 9.3 历史对比与解读

支持用户指定目标评估日和基准评估日，在相同发行日期组、地区、期限类别、债券口径下逐组比较。条件不足时按第9.2节处理。

每个可比组展示两日的加权收益率、合格样本数量、发行规模合计及其变化。统一采用“目标日减基准日”的方向：

```text
收益率变化（BP） =（目标日收益率（%）－基准日收益率（%））× 100
样本数量变化 = 目标日合格样本数量－基准日合格样本数量
规模合计变化 = 目标日发行规模合计－基准日发行规模合计
```

正值表示目标日高于基准日，负值表示低于基准日。差值依据已保存的计算精度生成，再做展示舍入；不先将两日数值显示舍入后计算差值。

- 用户询问“变化最大”等问题时，由程序按明确的变化指标排序；不同发行日期组、期限和债券口径分别比较，避免混成一个含义不清的排名。
- 任一日期没有有效结果，或任一侧某组收益率为空时，不计算该组收益率差，不将缺失值按0处理。其他有依据的项目可单独展示。
- 某日有效空组的样本数量与规模合计可以为0；整个日期没有结果时，这些项目也应标记为不可用。
- 两日规则或地区映射口径不一致时，明确提示差异，不直接表述为同口径变化。
- AI可以描述收益率变化是否同时伴随样本数量、规模合计变化，但不能仅凭这些汇总信息确定因果关系。

在不保存个券历史的情况下，本功能提供地区层面的事实对比，不承诺指出具体哪只债券造成变化。

### 9.4 每日行情摘要

每天的目标评估日汇总完整保存成功后，基于当日结果生成简报；用户也可以在AI助手中对当前所选日期与视图范围主动生成摘要。

自动摘要使用目标日之前最近一个已保存有效结果的评估日作为默认比较基准，并同时显示两个实际日期。该默认规则只用于自动选择摘要基准；用户明确指定基准日时，按其指定日期处理，缺少数据时说明缺失，不静默替换。

摘要内容包括：

1. **日期与范围**：目标评估日、基准评估日、覆盖的发行日期组、地区、期限及债券口径。
2. **主要变化**：在同口径下说明收益率变化，结合已保存的样本数量和发行规模合计描述可核对的事实。日常自动摘要覆盖当日汇总，手动摘要沿用用户明确选择的范围。
3. **数据状态**：说明无合格样本、缺少比较数据等影响阅读的情况，并提供相关表格入口。

处理边界：

- 历史起点等原因导致没有可用基准日时，只描述目标日已有结果，并注明无法进行历史比较。
- 数据源确认目标日无独立估值时，显示该日数据状态，不生成包含行情数值的摘要。
- 当日计算成功但全部债券被筛除时，摘要说明“已完成计算，无符合口径的债券”，不编造行情变化。
- 当日首次取数失败时，不生成当日行情数值摘要；用户主动解读已有成功快照时，须说明使用的是上次成功结果。
- AI服务不可用或生成失败时，汇总数据照常保存和展示，单独提示“摘要生成失败，可重试”。摘要重试只读取已保存结果，不重复触发Wind取数。
- 摘要绑定所依据的结果版本。同一日期重算成功后，旧摘要不能继续冒充新结果的解读；新摘要应基于当前有效结果重新生成。

### 9.5 AI入口与回答依据

工作台增加右侧“AI助手”面板，显示当前评估日期、发行日期组、地区范围和债券口径。提供“查询数据”“与另一天比较”“生成当日摘要”三个快捷入口，并支持用户输入自然语言。

AI回答中的数值、差值和排序必须来自实际查询及程序计算，附上评估日期、分析范围和可返回表格的入口。一次回答中的数值与相关汇总依据应来自明确且一致的结果版本；切换分析范围后，不将先前回答标为新范围的分析结果。

本期解读依据为工作台已保存的数据和更新状态。没有个券历史时不进行逐券归因；没有额外信息来源时，不把估值变化确定归因为政策、资金面或市场情绪，也不扩展为预测或交易建议。

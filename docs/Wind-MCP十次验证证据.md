# Wind MCP 十次请求验证证据

## 结论

本轮严格执行最多 10 次 MCP 协议请求：初始化、初始化通知、工具发现各 1 次，数据查询 7 次。无自动重试，未启动全量任务。数据查询均批量覆盖当前所需对照，未超预算。计费金额未由服务返回，不推算实际费用。

**取得了真实行情数值，但不是当前需求指定的中债估值收益率。** 2026-09-10，809336.IB（26河北23）的“收盘价收益率”为 **1.7691%**，809335.IB（26湖南15）为 **1.5905%**。原始响应的价格类型为“收益率”。没有明确的成交量/成交状态证明，因此只按来源命名为收盘价收益率，不称为已验证的实际成交收益率。

同一账号和服务能取得档案、跨市场代码及上述行情数值，而中债估值、实际估值日期仍为空。更换已确认的跨市场代码、历史日期及最新日期均未取得中债值。证据将问题缩小到指标数据覆盖、字段解析、账号指标权限或服务后端等可能范围，但服务未给出这些原因的诊断信息，仍不能断言某一种就是根因。

## 外部对照及其限制

[中债官方公开估值页](https://valuation.chinabond.com.cn/cbweb-mn/val/val_query_list?locale=zh_CN)在本轮查阅时显示：2026-09-10 的 03三峡债、代码 038006、上交所，估价净价 119.4742 元、估价收益率 1.8259%、修正久期 5.97。

本轮请求 `038006.SH`，MCP 却返回 `038006.IB`，上述字段均为空。这表明不能简单以“当日没有任何中债估值”解释所有空值，同时还暴露了代码解析/市场转换的待核查点。由于返回市场与公开页面不同，这不是严格相同市场代码的成功对照，不能凭此直接认定权限缺失或服务故障。

没有将公开网页数值写入工作台快照，也没有用它代替用户样本券数据。

## 是否能用已有数据完成分析

- 继续使用既定“中债估值收益率”口径：当前证据仍不足。不能以已取得的收盘价收益率代替，否则改变结果含义。
- 通过价格反算：上一轮 12 券中债净价、全价、应计利息均空，现有输入不够；本轮的收盘价收益率也不能倒推出中债估值。
- 日期：来源估值日期是元数据，不能从查询日期或行情交易时间计算出来。
- 条款：需要明确字段、募集说明书等证据，不能从一般债分类或空白条款推断。
- 全国完整名单：本轮未重复取数，之前完整性缺口仍在。两券对照不能证明全国覆盖。

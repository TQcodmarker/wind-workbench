# Wind 工作台取数需求清单

依据：工作区《地方债行情监测工具-需求文档》第 2、3、5 节与《地方债行情工作台-产品与技术设计文档》的接入验证要求。本文确定业务数据需求，不将应用字段名当作已验证的 Wind 字段编码。

## 1. 数据范围与粒度

以“单只债券 × 评估日期”为输入粒度，获取目标评估日属于约定 37 个发行地区的地方政府一般债、专项债全量名单及其数据。

- 地区：按既有文档列出的 37 个省、市和新疆生产建设兵团；计划单列市、兵团应独立归属，同一债券只归属一个地区。
- 估值历史：2026-09-01 至运行前一天；每日处理前一自然日。该起点不限制债券发行日期，早年发行、目标日仍属于债券范围的债券也要获取。
- 历史名单：按照目标日重建，不能仅用今天仍存续的名单；后续到期退出的券也可能属于过去的评估日。
- 全量：需要总数、完整清单以及可核对的分页/分批方式；不能用前 100 条或代表性样本代替。

## 2. 必需个券数据

| 业务数据 | 用途与口径 | 归属 |
|---|---|---|
| 稳定债券身份、证券代码、跨市场对应关系 | 区分经济意义上的不同债券；同券多市场上市只计一次。不能只删代码后缀或按简称合并 | 档案 |
| 发行主体与发行地区 | 映射到 37 个地区，区分省与计划单列市、新疆与兵团；上市交易地点不作为发行地区 | 档案 |
| 债券类型 | 明确区分地方政府一般债、专项债 | 档案 |
| 发行日期 | 按小于 2025-08-08 与大于等于 2025-08-08 分组；需确认字段是业务使用的发行日期，不能擅自用上市日或起息日替换 | 档案 |
| 实际发行规模及币种、单位 | 加权权重，统一为人民币亿元；不是评估日存量余额。存在续发行时，需确认累计方式，不把目标日之后新增的发行规模用于历史计算 | 档案及必要历史变更 |
| 提前偿还条款状态 | 明确“有／无／未知”，有则剔除，未知不按无处理；也可提供有正式定义和完整编码说明的等效字段 | 条款及必要历史变更 |
| 赎回条款状态 | 明确需求口径下是否存在赎回条款；有则剔除，未知不按无处理。需要条款定义、类型及值域说明 | 条款及必要历史变更 |
| 目标日中债估值收益率 | 加权计算对象，统一百分数，例如 1.75 表示 1.75%；需与需求所指收益率字段一致，保留来源精度 | 逐日估值 |
| 实际估值日期 | 必须能证明收益率属于目标日，不能只依赖请求中的日期或列标题 | 逐日估值 |
| 目标日剩余期限（年） | 按 ROUND_HALF_UP 取整分桶；必须对应目标日，不能使用今天的剩余期限。使用下一行权日口径或从到期日自行推算前，需确认与需求口径一致 | 逐日估值 |
| 数据状态／字段错误状态 | 区分正常值、缺失、来源错误、无当日估值、向前填充值；有效收益率 0 不能当缺失 | 来源状态 |

久期是原需求明确要求保留的基础字段，应一并获取，须说明久期类型和日期；它不用于当前的期限分桶或发行规模加权。久期缺失不应被自行新增为核心计算的剔除条件。

建议同时返回证券简称、证券全称、起息日、到期日及存续状态，方便人工对照和验证历史名单；它们不替代上述计算字段。若历史名单需要本地重建，则相应发行、到期、退出或兑付事件及其历史信息成为必需输入。

## 3. 接口能力与质量要求

1. 获取指定历史日的完整债券范围，并能通过总数和分页/分批结果核对完整性。
2. 按债券批量获取档案和指定日估值；明确数量上限、限流、排序、分页或分批参数及字段权限。
3. 返回字段定义、单位、日期参数、错误码与缺失值语义；说明历史覆盖范围以及默认是否向前填充。
4. 返回稳定跨市场身份对应关系；不能把 625 个市场代码未经去重当作 625 只独立债券。
5. 个别记录字段缺失按既定规则剔除并计数；整列必需信息不可用、名单截断、批次失败，不得包装成完整计算成功。
6. 当日无独立估值必须由来源状态或经验证的数据覆盖规则确认；鉴权成功、空表或全 null 不能单独证明全市场无数据。

## 4. 由工作台计算的结果

上述个券数据就绪后，由固定程序生成，不需要 Wind 直接提供最终 37 地区矩阵：

- 发行日期两组：2025-08-08 前；当天及以后。
- 剩余期限四舍五入后仅保留 3、5、7、10、15、20、30 年，其他年份排除。
- 按每个地区，分别计算整体、一般债、专项债。
- 加权收益率 = Σ（个券中债估值收益率 × 发行规模）÷ Σ发行规模。
- 同时保存合格样本数、发行规模合计、计算分子、生成时间及结果版本。
- 每个有完整汇总的评估日保存 37 × 2 × 7 × 3 = 1,554 个位置，空组收益率为空，不造出零收益率。

## 5. 当前 Wind MCP 的已知缺口

真实调用已拿到部分代码、名称、发行规模、发行起始日期、到期日和地区相关档案，但尚未完成全量与字段语义验收。上海名单查询只得到 100 个不同代码，计数报告 625；所测目标日中债收益率为空或无数据；条款字段未明确提供。历史期限和跨市场身份仍需核验。

这一结论仅针对当前账号、当前调用与已测日期，不能据此认定 Wind 所有产品都不支持上述数据，也不能确定缺失一定由权限造成。

## 6. 可转给 Wind 服务方的需求说明

我们需要指定历史评估日的地方政府一般债、专项债全量名单及逐券字段，覆盖约定的 37 个发行地区，历史自 2026-09-01 起。字段包括证券代码与稳定跨市场身份、发行主体和地区、一般/专项分类、发行日期、实际发行规模及续发行历史口径、提前偿还和赎回条款、目标日中债估值收益率及实际估值日期、目标日剩余期限、久期及数据状态。请提供对应产品/API、正式字段编码与定义、单位和值域、历史权限与覆盖、完整分页/分批方案，以及一组可核对的真实样例。发行规模用于加权，不使用存量余额；历史数据不得自动填充或使用今日值替代。当前 MCP 的上海全量请求报告 625 条但仅返回 100 条，所测中债估值为空，条款字段也未明确返回，请协助确认正确取数方式。

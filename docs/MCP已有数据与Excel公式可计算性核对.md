# MCP已有数据与Excel公式可计算性核对

核对日期：2026-09-12。业务目标日：2026-09-10。

本次仅复用保存的MCP原始响应、JSON证据与SQLite来源记录，未新增Wind或网络查询，未修改应用代码、原Excel或来源数据库。对照公式见《原Excel公式逻辑提取.md》。数据库通过只读连接访问；演示库和模拟测试结果不作为真实数据证据。

## 结论

**不能计算原Excel的全部数据，也不足以发布全国正式汇总。** 当前能计算部分样本的地区、类型、发行日期分组、期限分类和发行规模合计；收益率、票息调整收益、曲线偏离、综合收益区间统计仍缺上游输入。

与此前只有概念公式时相比，现在K/P、L、M、N、Q、T的原始计算关系已经提取清楚。主要障碍已经可以具体定位到字段和数据覆盖；数学公式已知不意味着输入值可推导。

## 2. 逐项计算判断

以下y=中债估值收益率，c=票面利率，b=曲线4202在单券期限上的收益率，d=Excel要求的中债修正久期，a=评估日余额。

| 结果 | 公式/依赖 | 当前能否计算 | 原因 |
|---|---|---|---|
| 地区与类型 | 主体映射、类型归并 | 可以，限已有样本 | 12券档案齐全 |
| T发行日期分组 | 发行日期<2025-08-08为1，否则0 | 可以，限已有样本 | 12券日期齐全，均为0 |
| N期限分类 | 期限≥25归30，否则ROUND(期限,0) | 可以，限12券目标日数据 | 12券目标日剩余到期期限齐全 |
| 样本数量、发行规模合计 | COUNT、SUM原始发行规模 | 可以，限样本档案统计 | 不代表通过估值和条款筛选的合格样本 |
| J个券中债估值 | 来源字段 | 不可以 | 有效中债值缺失 |
| I地方债曲线 | 曲线4202、日期、实际剩余期限 | 不可以 | 没有曲线值/节点；曲线代码本身不是数值 |
| K/P免税收益、综合收益 | y+0.25c | 不可以 | y和MCP票面输入未齐全 |
| L非免税曲线偏离 | (y-b)×100 | 不可以 | y、b缺失 |
| M免税曲线偏离 | (y+0.25c-1.25b)×100 | 不可以 | y、c、b缺失 |
| Q久期×余额 | d×a | 不能完整按原口径计算 | 12券缺d和目标日a；旧上海久期还需确认来源及同券同日余额匹配 |
| 分地区分期限平均中债估值 | 按地区、N、T、类型平均J | 不可以 | J缺失，市场样本也不完整 |
| 此前工作台的发行规模加权估值 | Σ(y×发行规模)/Σ发行规模 | 不可以 | 权重部分已有，y缺失；正式发布还需条款和全集 |
| 综合收益区间的金额、占比 | 按P分档，再合计a | 不可以 | 既缺P用于分档，又缺同一全集的目标日余额；已有局部余额不够 |
| 综合收益区间加权久期 | 按P分档后Σ(d×a)/Σa | 不可以 | 分档依据、余额和指定久期未齐全 |
| Sheet1历史曲线利差与累计 | 地方债/国债对应历史曲线及日期 | 不可以从现有MCP数据重建 | 所需历史曲线序列未取得；Excel中该分支原本使用另一外部数据函数 |

收益公式的输入y、c、b彼此不是已知的函数关系。发行规模、地区、发行日期、剩余期限无法唯一确定这三个收益率/利率值；AI也不能从这些档案补造它们。即使从Excel旧缓存补入票面，目标日中债估值和曲线缺口仍然存在。

## 4. 多次取数合并时的限制

1. 旧上海universe两张100行表重复，不能合并为200条。与旧valuation的100代码清单只有16代码交集，不能按行号拼接。
2. 旧批量期限字段为“剩余期限_下一行权日”，没有明确目标日限定，不能替代最近12券已明确返回的目标日“剩余到期期限”。例如233890.SH批量为8.474，与单券9月11日值相同，而单券9月10日为8.4767，存在日期或字段口径差异。
3. 两券跨市场对应关系已明确返回：809336.IB→236633.SH、809335.IB→236603.SH；这不证明全市场身份均已齐全。
4. 两券“到期偿付”是偿还方式描述，不能单独证明不存在提前还本约定或发行人赎回权。
5. 最新收盘收益率返回0和20260911时间，没有中债来源及估值日期含义，不能作为9月10日中债数据。
6. 原Excel当前保存的评估日期为2026-06-17，现有核心MCP样本目标日为2026-09-10。旧Excel动态字段不能直接填入9月10日缺口。Excel可用于公式核对和旧快照复算，不构成每日自动更新的数据补齐方案。

## 5. 完成全部指标还需哪些输入

若仅完成此前的发行规模加权中债估值，优先补齐：目标日中债估值收益率及实际估值日期、明确提前还本/赎回状态、可核验的历史债券全集与发行规模/身份口径。

若要覆盖原Excel全部计算，在上述基础上还需：票面利率、目标日存量余额、目标日中债修正久期、曲线4202在实际剩余期限上的收益率（或足够节点与正式插值规则），以及Sheet1使用的历史地方债和国债曲线序列。

只有原始数据已经齐全后，K/P、L、M、N、Q、T和各项汇总才可由固定程序计算，无需逐项向MCP索取派生结果。若想采用已取得的收盘价收益率，应另行明确为新的指标口径，不替换原表J列。

本次结论针对已保存的当前账号、服务、查询和样本；不能由字段为空判断Wind所有产品都不支持，也不能确认缺失一定由权限造成。

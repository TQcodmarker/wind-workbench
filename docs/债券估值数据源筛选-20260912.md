**推荐的落地顺序**

1. 先核查是否已有 Wind Client API 或中债产品授权。已有授权可优先取得小批同券同日数据，或通过授权导出文件导入工作台，减少新增采购；Wind MCP Key 本身不证明拥有这些权限。
2. 没有相应授权时，以中债官方为第一询价对象，要求“国债＋地方政府一般债／专项债”的逐券估值及历史交付。iFinD 对同一份样本清单提供试取结果，作为价格和覆盖的比较对象。本次不引用其他机构历史采购价作为当前报价。
3. 验收样本包含 809336.IB、809335.IB，以及国债、新发行券、历史已到期券、跨市场代码；分别检查估值收益率、净价、久期、原始日期与单位、代码覆盖和历史查询能力。中债空值不得用当前收盘 YTM 覆盖。
4. 通过小批样本后，再做全量覆盖评估。收益率曲线用于基准展示和有明确规则的利差分析，不能代填个券收益率。

接入时还应读取最新数据标准：[中债 2026-08-28 公告](https://www.chinabond.com.cn/xxwsy/sy_zdgz_ath/202608/t20260828_855338651.html)已提供新版估值数据标准及样例，预计 2026-12-11 调整部分指标并设置三个月新旧并行期。该公告可用于规划字段版本适配，样例不视为用户清单的真实行情。

当前可明确给出的结论是：有适合补齐目标数据的官方产品路线，也有可见真实样本；尚未核实一个免费、全量、可持续批量取得地方债／国债逐券中债估值的接口。完整接口是否“可用”，仍需指定账号与样本验收。

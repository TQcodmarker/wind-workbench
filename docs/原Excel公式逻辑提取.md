## 1. 数据结构与日期

工作簿共9张工作表。“原数据-WIND”含20列，数据位于第2—14024行，共14,023条证券代码记录。代码无完全重复；这不等于已经核验跨市场经济身份去重，也不证明市场名单完整。

日期依赖为：

`分地区分期限-非免税!B2 → 原数据-WIND!A1 → 个券日期相关取数公式`。

`分地区分期限-非免税!B2` 与 `分地区分期限-免税!B2` 均为 `=[1]!TDaysOffset(TODAY(),"Offset=-1")`。公式调用 Wind 的交易日偏移函数，以 TODAY 为基准偏移-1，实际日历行为仍依赖插件。原表不是直接用 TODAY()-1。当前保存的评估日期为2026-06-17。

A列证券代码是已有固定清单，没有发现自动生成全量名单的单元格公式。工作簿中的 [1]! 前缀是外部链接/插件函数引用，并非本地计算规则。

## 3. 原数据-WIND：本地计算

设 y=J列中债估值收益率，c=G列票面利率，b=I列曲线收益率，t=D列剩余期限，d=H列久期，a=E列余额。原表利率以百分数数值保存，例如1.89表示1.89%。

| 列 | 指标 | 第2行公式或等价表达式 | 计算逻辑 |
|---|---|---|---|
| K | 免税收益 | `=G2/4+J2` | y+0.25c |
| L | 非免税曲线偏离 | `=IF(I2=0,"",(J2-I2)*100)` | b为0时为空；否则(y-b)×100，单位BP |
| M | 免税曲线偏离 | 等价于 `=IF(I2=0,"",(J2+G2/4-I2*1.25)*100)` | b为0时为空；否则(y+0.25c-1.25b)×100，单位BP |
| N | 期限（四舍五入） | `=IF(D2>=25,30,ROUND(D2,0))` | t≥25直接归30；t<25按四舍五入取整数 |
| P | 综合收益 | `=J2+0.25*G2` | 与K列数学上完全相同 |
| Q | 久期*余额 | `=H2*E2` | d×a，用于后续余额加权久期 |
| T | 发行日期分组 | `=IF(--S2<DATE(2025,8,8),1,0)` | 日期早于2025-08-08记1，否则记0；双负号将日期文本转换为可比较数值 |

M2实际保存的公式为：

`=IF(I2=0,"",([1]!b_info_couponrate2(A2)/4+[1]!b_anal_yield_cnbd(A2,$A$1,1)-[1]!b_calc_curve_chinabond("4202",$A$1,D2)/4*5)*100)`

它重复调用Wind函数，上述等价式以这些函数返回值分别与G、J、I一致为前提。M并非简单的“免税收益减去原曲线”：基准曲线还乘了1.25。

原表能证明存在0.25和1.25这两个系数，不能证明其税务适用依据。K、P、M没有根据T列决定是否进行调整，同一套公式向所有行填充。

## 4. 地区与期限汇总

“分地区分期限-免税”和“分地区分期限-非免税”各有36地区×7期限=252组。七期限为3、5、7、10、15、20、30；C、D、E列分别为整体、一般债、专项债。

免税表C5：

`=IFERROR(AVERAGEIFS('原数据-WIND'!$J:$J,'原数据-WIND'!$B:$B,'分地区分期限-免税'!$A5,'原数据-WIND'!$N:$N,'分地区分期限-免税'!$B5,'原数据-WIND'!$T:$T,1),"")`

其逻辑是：按地区B、期限N、日期组T筛选，对中债估值J取算术平均。一般债与专项债再增加F列等于对应类别的条件。非免税表将T条件改为0。

因此：

1. 汇总对象是J列中债估值，未使用K/P的票息调整收益，也未使用L/M利差。
2. 各券等权，未按余额或发行规模加权。整体直接平均匹配个券，不是两类平均值再简单平均。
3. 平均公式没有O/R条款筛选条件，也没有余额必须大于0、来源日期验证、跨市场去重条件。
4. N为空的行不匹配目标期限，因而被间接排除。
5. IFERROR将无匹配和其他计算错误均显示为空，不能仅凭空白判断原因。零收益率若匹配筛选，会作为数值参与平均。

复核示例：非免税表A122:E122为河北省10Y。按缓存的地区、期限和T=0筛选得到12条记录，其J列算术平均为1.8325166666666666%，与C122一致。

“分区域”表负责把长表按地区及期限重新排列。地区档位属于表内展示安排，未在个券公式中看到量化分档算法。

## 5. 综合收益分布与加权久期

透视表配置以P列综合收益分组：起点0、终点4、步长0.5，并设上下界外组。保存视图显示0.5—1、1—1.5、1.5—2、2—2.5、2.5—3、3—3.5等组。恰好位于边界值时如何归属，应在迁移时单独验证，不能仅由标签认定开闭区间。

每组汇总E列余额与Q列久期×余额。数据透视表B15:E17进一步计算：

- 金额=区间内余额合计。
- 金额占比=区间余额÷全体透视汇总余额M12。
- 加权久期=区间内Σ(久期×余额)÷区间内Σ余额。

例如B15=E12，B16=B15/$M$12，B17=F12/E12。最后由“综合收益范围统计【地方债】”B2:E4链接这些结果，展示1.5—2、2—2.5、2.5—3、3—3.5四档。

这是余额加权久期；没有看到此分支计算加权收益率。

## 6. 其他工作表的独立逻辑

Sheet1为另一条曲线历史分析链，A1调用外部函数`[2]!HX_IFIND_EDB(0)`。它不是从“原数据-WIND”汇总而来。

- H:N列将日期、地方债5/7/10/15/30年曲线及国债10年曲线映射到展示列。
- O5=`(J5-N5)*100`：地方债10年收益率减国债10年收益率，转BP。
- P5=`IF(YEAR(H5)=2024,O5+P6,0)`：仅对2024年的行，将本行利差与下一行累计值相加；其他年份为0。数据按日期倒序，因此这是按该表顺序累加利差水平，既不是日变化值，也不是投资累计回报。
- H:L只填598行，而M:N/O/P向更远行延伸，存在覆盖不一致，应在使用该历史分析前核对。

Sheet2没有公式，只包含汇总展示模板。

## 8. 可还原的数据处理流程

固定证券代码清单 → 按评估日期调用Wind档案、估值及曲线 → 截取地区与类型 → 计算K/L/M/P收益与偏离指标、Q久期乘余额 → 按N期限和T发行日期分组 → 分别生成地区期限等权估值汇总，以及综合收益区间余额与加权久期统计 → 排列展示。

自动更新债券全集、明确的条款剔除、完整缺失处理、历史快照保存和可靠刷新机制，不能从现有公式中认定已经实现。

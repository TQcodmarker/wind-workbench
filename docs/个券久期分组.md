# AKShare 个券修正久期与汇总分组

当前规则：`rules-akshare-v2-estimated-duration`。

## 指标与计算

收益率仍采用目标日的个券公开成交到期收益率，汇总仍按发行规模加权。剩余期限保留为 `(最终到期日－评估日)/365`，仅作信息展示及曲线参考，不再决定汇总分组。

个券修正久期使用未来本息现金流自行计算。令每年付息次数为 m、名义年收益率为 y，第 i 笔现金流距离评估日的付息期数为 nᵢ：

- 现值 PVᵢ = CFᵢ / (1+y/m)^nᵢ。
- 麦考利久期 = Σ(PVᵢ × nᵢ/m) / ΣPVᵢ。
- 修正久期 = 麦考利久期 / (1+y/m)。

第一期不足整期时，按下一付息日与评估日的实际天数，除以该完整付息周期的实际天数。后续按完整期数递增；采用合同日历日期，不推算节假日顺延，评估日当天的本息按已支付处理。金额计算使用 Decimal。

这套方法是本地模型，不是 AKShare、Wind 或中债直接发布的久期。来源输入、方法版本和假设保存在每只债券的 `durationCalculation` 中，原始 AKShare 静态详情与行情响应不被改写。

## 缺失输入与估算假设

常规计算需要固定票息、年/半年付息频率、起息日、首次付息日、到期日，以及同日个券收益率。缺少这些字段，或付息安排不规则、浮息、存在无法建模的选择权时，保留行情但不纳入久期分组。

公开资料尚未核验还本安排、计息基准、收益率复利规则时，明确标为“估算”：假设到期一次还本、Actual/Actual 付息周期分数、按付息频率复利。`exerciseInfoFlag=否` 不构成一次还本的证据。

原始用户清单里明确的提前偿还或赎回提示作为保守约束，保留代码与单元格来源。已有提前还本提示却无可靠还本计划的债券不采用一次还本假设；原表的 0 不被当作已核验无条款。

已取得完整且有来源的还本计划时，支持按原面值 100 的逐期本金偿付百分比计算，并按每期偿还前本金计息。计划须合计 100、结束于到期日、落在规则付息日。即使标为“计算值”，也仍是本地计算值。

## 就近分档

不先将久期取整，直接就近归入 3、5、7、10、15、20、30 年档。相同距离归较大档；正久期低于最小档或高于最大档时归端点档。

| 久期档 | 修正久期范围 |
|---|---|
| 3 年 | 0 < D < 4 |
| 5 年 | 4 ≤ D < 6 |
| 7 年 | 6 ≤ D < 8.5 |
| 10 年 | 8.5 ≤ D < 12.5 |
| 15 年 | 12.5 ≤ D < 17.5 |
| 20 年 | 17.5 ≤ D < 25 |
| 30 年 | D ≥ 25 |

例如久期 11 年归 10 年档，12.5 年归 15 年档。久期 13.05 年、剩余期限 16.48 年的债券归 15 年久期档。

## 页面与数据版本

明细同时展示修正久期、估算标识、久期档与剩余期限。详情展示现金流输入和假设；CSV 导出包含状态、分档及假设。汇总显示其中使用估算久期的样本数量。指数久期、指数凸性和指数基点价值继续仅作为参考。

启动升级会用本机已保存的原始输入重算旧 AKShare 数据，不重新请求行情。替换前将旧完整数据及规则版本保存到 SQLite 的 `akshare_dataset_archive`。新旧规则版本不能直接进行日间比较。Wind 与演示数据继续使用各自原有规则。

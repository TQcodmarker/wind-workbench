补充更正：前轮遗漏了中债指数接口。随后5次实际请求已取得地方政府债指数的财富、平均收益率、平均久期，以及浙江地方债和固定利率国债指数的平均收益率，最新日期均为2026-09-11。免费版可增加市场与地区观察功能，详见[中债指数补充实测](/D:/code/wind工作台/docs/AKShare中债指数补充实测-20260912.md)。下文12个用例和20次请求仅指此前验证批次，358个代码也仅指逐券成交匹配。

已在本机实际安装并运行 AKShare 1.18.94。结论：免费获取国债曲线、部分逐券成交收益率和发行资料可行；本次验证不足以补齐当前清单全部地方债／国债的逐券中债估值，也不能直接替换现有 Wind 收盘价 YTM。

测试使用独立环境 `.tmp/akshare-venv`，Python 3.14.6。首轮 9 个用例、补充 3 个用例，共 20 次公开 HTTP 请求，9 个用例返回非空表格、3 个失败。失败与补参成功分别留存，不能把用例成功率当作债券覆盖率。没有调用 Wind、使用付费服务或修改业务数据库。

**接入前已经确认需要处理的问题**

- 发行资料跨市场重复：地方债169行中银行间67行，按全名和日期组合为67组；该分组尚未验收为经济实体身份。同一债券的沪、深、银行间发行金额不能重复加权。国债38行按全名和日期组合为12组，增发金额不能直接当首次发行规模。
- 日期校验：储蓄国债261707、261708被SDK输出为起始09-19、终止09-10。原始字段为 `F004D=09-19`、`F003D=09-10`，SDK显式将它们映射为起始／终止。字段语义仍需核对，当前应排除异常记录，不擅自交换日期。
- 本次09-01至09-11发行窗口与旧清单精确命中0，不等于历史发行资料覆盖为0。没有查询全历史，也没有证实发行资料能补齐所有缺失档案。
- 收盘曲线和报价须补全分页。成交、报价须保存原始代码、市场、来源时间；缺失值和冲突不能直接替换成0或随意取一行。
- 中债国债曲线、中国货币网收盘曲线属于不同来源。同日3年值分别为1.2504%和1.2531%；后者虽有15／20年，也不能拼接后标为同一条中债曲线。

**对零付费版本的判断**

可采用AKShare作为免费来源接入工具，先实现“国债曲线走势＋有成交地方债的收益率＋发行资料”，按来源分别展示，并显示日期和覆盖率。需要处理上述分页、字段和查询参数问题，不能直接拿成功返回的表格当完整生产数据。

“每只地方债／国债每天都有官方中债估值净价、估值收益率、久期”等目标，当前没有取得满足该要求的全量免费数据。发行价、成交价、成交收益率和曲线点都不能冒充个券中债估值。已有Wind历史数据继续保留原来源与日期，公开成交应作为独立口径。

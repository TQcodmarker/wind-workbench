# 到期收益率与 MCP 数据使用规则

按用户最新要求，先使用 Wind MCP 已返回的数据，暂不采集、记录提前偿还和发行人赎回信息，也不依据这两项筛选债券。

## 数据使用

- 查询目标仍为指定日期的收盘价到期收益率，单位为百分数；`1.75` 表示 `1.75%`。
- 直接采用 Wind MCP 返回的非空数值，有效零值保留。已认可的“收盘价收益率”“到期收益率”等名称映射至工作台收益率字段，不额外要求同一响应提供指标类型、价格依据或实际日期证明列。
- 按查询日期归档，`dateBasis=query_date`。返回中附有原始日期时保留该信息，不将查询日期描述为来源证明的实际成交日期。
- 保留原始响应、原始字段名、单位和逐字段来源。暂不从新响应提取条款到规范化个券或筛选记录；既有历史原始证据继续保留。
- 缺失的计算必需数据仍保留为缺失；不能用余额代替发行规模、用票息代替收益率或用零补空值。

## 计算与条款

当前仍按发行日期、地区、债券类型和剩余期限分组，并使用发行规模加权：

`汇总到期收益率 = Σ（单券收盘价到期收益率 × 发行规模）/ Σ发行规模`

提前偿还和发行人赎回不再是必需字段，也不构成纳入或剔除条件。新记录不生成“无提前偿还”“无赎回”之类的推断值。

剩余期限采用返回值，以 ROUND_HALF_UP 取整后归入 3、5、7、10、15、20、30 年组。证券身份去重、非正发行规模排除和空组处理继续适用。已返回的久期、票息、余额等字段可保留使用；原表中债久期和 4202 曲线的空值不阻断当前收益率汇总，也不生成依赖缺失输入的派生结果。

## 版本与历史

新规则版本为 `rules-v3-mcp-values-no-clauses`，保存以下策略：

- `clausePolicy=not_collected_or_filtered`
- `dataAcceptance=mcp_returned_values`
- `dateBasis=query_date`

旧 `rules-v1` 中债快照和 `rules-v2-ytm-close` 快照保留各自的日期验收及条款筛选含义。规则抽屉读取快照保存的规则；旧核验报告明确标为历史结果。不同规则版本不直接计算涨跌，自动摘要只选兼容的基准日。旧排队任务不能改用新规则执行。

原 Excel、旧原始响应和历史失败证据没有改写。本轮使用已有返回和离线样例检查规则，不新增付费查询；单券复核不代表完整地区或全国覆盖。
